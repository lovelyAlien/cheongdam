## 1. 찾기

### S-01 공고 목록 (홈)

**목적:** 조건에 맞는 공고를 빠르게 훑고 상세로 들어간다. 지금 조건을 알림으로 저장하는 입구이기도 하다.

**진입:** 첫 방문, 로고, 상세에서 뒤로 가기, 공유 링크(필터가 담긴 URL), 알림 메일의 `N건 더 보기`.

**와이어프레임 (모바일)**

```
┌────────────────────────────────┐
│ 청담               알림 받기  안내 │
├────────────────────────────────┤
│ 🔍 단지명 검색                   │
│ [필터 3] [서울✕][경기✕][접수중✕] │  ← 적용된 조건 칩, 가로 스크롤
│ 공고 24건        접수 임박순 ▾   │
│ [🔔 이 조건으로 알림 받기]        │
├────────────────────────────────┤
│ ⓘ 정보가 없는 무순위·재공급 공고  │
│   5건은 제외했어요 [포함해서 보기] │
├────────────────────────────────┤
│ [접수 중 D-2] [정정]             │
│ ○○자이 더 센트럴        민영     │
│ 경기 수원시 장안구               │
│ 3.2억 ~ 5.2억 · 59~84㎡ · 812세대│
│ 특공 10.20(화) → 2순위 10.23(금) │
│ #신혼부부 #생애최초 #다자녀 +2   │
├────────────────────────────────┤
│ [접수 예정 D-5] [무순위]         │
│ ...                            │
├────────────────────────────────┤
│           [ 더 보기 ]           │
└────────────────────────────────┘
```

**구성 요소**

| 영역 | 요소 | 표시 데이터·규칙 | 요구사항 |
|---|---|---|---|
| 검색 | 단지명 검색창 | `HOUSE_NM` 부분 일치. 입력 후 300ms 디바운스 또는 엔터로 검색. 공백·괄호 표기("(조합원 취소분)")를 무시하고 비교 | F3-8 |
| 필터 바 | `필터 N` 버튼 | 기본값과 다른 조건 개수. 누르면 S-02 | F3-1~7 |
| | 적용 조건 칩 | 조건 값마다 칩 하나, `✕`로 개별 해제. 지역 3개 이상이면 `서울 외 2` | |
| 결과 | 결과 수 | `공고 N건` | |
| | 정렬 | `접수 임박순`(기본) / `최신 공고순` | F3-10 |
| | 알림 받기 버튼 | 현재 필터 조건으로 S-08 구독 시트를 연다. 검색어는 조건에 넣지 않는다(검색은 일회성) | F3-11, F7-1 |
| | 제외 안내 배너 | P-04 | F3 |
| 카드 | 배지 | 접수 상태(P-01) → 공고 유형(P-02) → 정정(P-08) 순 | |
| | 단지명 + 주택 구분 | `HOUSE_NM` 두 줄 넘으면 말줄임, `HOUSE_DTL_SECD_NM` | F2-1 |
| | 위치 | `SUBSCRPT_AREA_CODE_NM` + `HSSPLY_ADRES`의 시·군·구까지 | F2-1 |
| | 핵심 숫자 | 분양가 범위 · 전용면적 범위 · 총 세대수(P-03) | F2-1 |
| | 일정 요약 | 접수 예정·중: 첫 접수일 → 마지막 접수일. 마감: `당첨자 발표 10.30(금)` | F2-1 |
| | 특별공급 태그 | 세대수 1 이상인 유형만, 세대수 많은 순 최대 3개 + `+N`. 필터에서 고른 유형은 강조색 | F3-5 |

**정렬 규칙 (F3-10)**

- **접수 임박순(기본):** 접수 중(종료일 가까운 순) → 접수 예정(시작일 가까운 순) → 일정 확인 필요 → 마감(종료일 최근 순). 접수 시작일 순으로만 정렬하면 이미 접수 중인 공고가 맨 뒤로 밀리기 때문이다(D-01).
- **최신 공고순:** `RCRIT_PBLANC_DE` 내림차순, 같으면 공고번호 내림차순.

**동작**

- 한 번에 20건을 보여 주고 `더 보기`로 20건씩 더 불러온다. 무한 스크롤을 쓰지 않는 이유: 푸터의 면책·출처에 닿을 수 있어야 하고, 상세에서 돌아왔을 때 위치 복원이 쉽다.
- 필터·검색어·정렬 상태를 URL 쿼리에 남긴다. 예: `/?region=서울,경기&status=upcoming,open&supply=newlywed&sort=deadline`. 공유·북마크로 같은 목록을 다시 볼 수 있고, 알림 조건(6.4)도 같은 형식으로 저장한다.
- 상세에서 뒤로 오면 스크롤 위치와 불러온 개수(더 보기 횟수)를 복원한다.
- 마감 공고는 접수 종료일로부터 1년 이내인 것만 보여 준다(D-02).

**상태·예외**

| 상황 | 화면 |
|---|---|
| 결과 0건 | `조건에 맞는 공고가 없어요.` + 결과가 생기는 완화 제안 버튼 최대 2개. 예: `[마감 공고도 보기 (8건)]`, `[분양가 조건 빼기 (3건)]`. 제안은 조건을 하나씩 뺐을 때의 건수로 계산해 건수가 많은 순. `이 조건으로 알림 받기`는 그대로 둔다(지금은 없어도 새 공고를 받을 수 있다) |
| 검색어 결과 0건 | `'○○' 단지를 찾지 못했어요. 필터 조건 안에서만 찾았어요.` + `[필터 풀고 검색]` |
| 목록 API 오류 | `공고를 불러오지 못했어요.` + `[다시 시도]` |
| 마지막 수집이 24시간 넘게 실패 | 결과 수 옆에 `마지막 업데이트 10.18(일) 06:00` 경고색 표시 (E-10) |

**관련 검수:** #1~#7

### S-02 필터

**목적:** 공고 속성으로 목록을 좁힌다.

**형태:** 모바일은 전체 높이 바텀시트, 하단에 `초기화` / `공고 N건 보기` 버튼. 데스크톱은 목록 왼쪽 고정 패널, 바꿀 때마다 즉시 적용.

- 모바일에서는 조건을 바꿀 때마다 `공고 N건 보기`의 N을 갱신한다. 0건이 되는 조합을 적용 전에 알 수 있게 하기 위해서다.

**필터 사양**

| 순서 | 필터 | 컨트롤 | 값 | 기본값 | 요구사항 |
|---|---|---|---|---|---|
| 1 | 접수 상태 | 칩 다중 선택 | 접수 예정 / 접수 중 / 마감 | 접수 예정 + 접수 중 | F3-4 |
| 2 | 지역 | 칩 다중 선택 | 시·도 17개(서울, 부산, 대구, 인천, 광주, 대전, 울산, 세종, 경기, 강원, 충북, 충남, 전북, 전남, 경북, 경남, 제주). 수도권 묶음 칩(서울·경기·인천) 별도 제공 | 전체 | F3-1 |
| 3 | 특별공급 유형 | 칩 다중 선택, 칩마다 `?` 툴팁([DATA.md 3장](DATA.md#3-툴팁-용어-설명-초안-법령-검수-전)) | 신혼부부, 생애최초, 다자녀, 신생아, 노부모부양, 청년, 기관추천 | 선택 안 함 | F3-5, F2-4 |
| 4 | 분양가 | 최소·최대 드롭다운 | 1억 단위 0~15억, `15억 이상` | 제한 없음 | F3-6 |
| 5 | 전용면적 | 칩 다중 선택 | 60㎡ 이하 / 60~85㎡ / 85㎡ 초과 | 선택 안 함 | F3-7 |
| 6 | 공고 유형 | 칩 다중 선택, 칩마다 `?` 툴팁 | 일반 분양 / 무순위 / 불법행위 재공급 | 전체 | F3-3 |
| 7 | 주택 구분 | 칩 다중 선택, 칩마다 `?` 툴팁 | 민영 / 국민 | 전체 | F3-2 |

- 순서는 입문자가 많이 쓸 것으로 예상하는 순이다. 런칭 후 소수 사용자 인터뷰로 조정한다.
- 전용면적 구간은 60㎡·85㎡ 기준이다. 국민주택규모(85㎡)와 대부분의 공고에서 주택형이 갈리는 기준이라 입문자에게도 "59, 84"로 익숙하다.
  - 구간 경계: `60㎡ 이하` = 전용 ≤ 60, `60~85㎡` = 60 < 전용 ≤ 85, `85㎡ 초과` = 전용 > 85.
- 특별공급 유형 아래에 보조 문구: `무순위·재공급 공고는 특별공급 정보가 없어 제외돼요.`

**조건 결합 (F3-9)**

- 서로 다른 필터는 AND, 한 필터 안의 여러 값은 OR.
- 주택형 단위 필터(특별공급 유형, 분양가, 전용면적)는 **한 주택형이 모두 만족**해야 그 공고가 나온다.
  - 예: 신혼부부 + 분양가 5억 이하 + 60~85㎡ → "전용 84㎡ 이면서 최고 분양가 5억 이하이면서 신혼부부 세대수가 1 이상"인 주택형이 하나라도 있는 공고.
  - 59㎡는 4억에 신혼부부 0세대, 84㎡는 6억에 신혼부부 20세대인 공고는 나오지 않는다.
- 상세 화면의 주택형 표에서 필터 조건을 만족하는 주택형을 강조해, 왜 이 공고가 나왔는지 보이게 한다(S-03 블록 A).

**관련 검수:** #2~#5

## 2. 공고 상세 (S-03)

**목적:** 공고 하나에 대해 "언제 무엇을 해야 하는지"(블록 A), "당첨되면 무엇이 따라오는지"(블록 B), "내 공급 유형의 조건이 무엇인지"(블록 C)를 원문 근거와 함께 한 화면에서 확인하고, 일정을 캘린더에 넣는다.

**진입:** S-01 카드, 공유 링크, 알림 메일(M-02, M-03).

| A | 핵심 요약, 일정 + 캘린더, 주택형 | API | 수집 즉시 | F2-1, F2-7 |

### 블록 C: 공급 유형별 자격 조건표 (F5)

**목적:** 내가 넣으려는 공급 유형의 조건을 한 줄씩 읽고 스스로 체크한다. 서비스는 체크 결과로 판정하지 않는다.

| 요소 | 규칙 | 요구사항 |
|---|---|---|
| 공급 유형 칩 | 이 공고에 있는 유형만(세대수 1 이상인 특별공급 유형 + 일반 1순위·2순위, 무순위 공고는 `무순위` 하나). 칩에 세대수 표시. 하나만 고른다. `?` 툴팁([DATA.md 3장](DATA.md#3-툴팁-용어-설명-초안-법령-검수-전)) | F5-1 |
| 기본 선택 | 목록 필터에서 고른 특별공급 유형이 이 공고에 있으면 그 유형(여러 개면 세대수 많은 것), 없으면 `일반 1순위` | F5-1 |
| 조건 목록 | 고른 유형에 적용되는 조건(대상이 `전체`인 조건 + 그 유형 조건)을 분류 순서(공통 자격 → 청약통장 → 일반공급 순위 → 특별공급 → 소득·자산)로 나열 | F5-1 |
| 조건 행 | 체크박스 + 쉬운 문장([DATA.md 2장](DATA.md#2-추출-결과) 요건 문장) + 근거 칩. 문장 안 용어에 툴팁 | F5-1, F5-2, F2-4 |
| 기준 표 | 소득·자산 조건은 공고문의 기준 금액 표를 `기준 표 보기`로 펼친다. 금액을 입력받지 않는다 | F5-1 |
| `원문 확인 필요` 조건 | 회색, 체크박스 없음(P-05) | F5-2 |
| 체크 개수 | `N개 중 M개 체크`. 모두 체크해도 다른 문구를 띄우지 않는다 | F5-3 |
| 일반 규정 | 「주택공급에 관한 규칙」을 옮긴 일반 규정은 `일반 규정 (N)`으로 접어서 맨 아래에 둔다. 체크박스 없음 | F2-2 |

### 블록 D: 정정 이력 (F2-6)

- 정정이 1회 이상일 때만 상세 맨 아래(원문 버튼 위)에 둔다.
- 이력 항목: 감지 일시, 바뀐 항목, 이전 값 → 새 값. 예: `10.18 · 1순위 접수일 10.21 → 10.23`
- 바뀐 항목은 정정 PDF 첫 쪽의 정정 안내 상자(변경 전/후)에서 뽑는다([기술 노트 2장](../TECH_NOTES.md#2-기술-고려사항)). 뽑지 못하면 `공고문이 새로 올라왔어요. 내용을 다시 정리했어요.`만 보여 준다.
- 일정이 바뀐 정정이면 `캘린더에 추가한 일정이 있다면 다시 추가해 주세요. [캘린더에 추가]`를 함께 보여 준다(E-19).

### 무순위·재공급 공고의 차이

- 블록 A 일정은 접수 기간 한 단계와 당첨자 발표·계약만 표시한다.
- 주택형 표의 특별공급 유형별 세대수는 P-04 문구로 대체한다.
- 블록 C의 공급 유형 칩은 `무순위` 또는 `재공급` 하나다.

**상태·예외:** 준비 상태는 P-06, 정정 중 표시는 P-08, 공고 삭제는 E-08, 같은 단지 공고는 E-09.

## 3. 원문 (S-06 원문 보기)

**목적:** 근거 칩에서 원문 해당 쪽을 바로 확인한다. (F6-1, F6-2)

- **형태:** 서비스 안의 PDF 뷰어. 모바일은 전체 화면, 데스크톱은 상세 오른쪽 분할 패널(상세를 보면서 원문을 함께 본다).
- **진입 시 동작:** `?page=` 쪽으로 이동하고, 근거 문구를 텍스트 레이어에서 찾아 형광펜으로 강조한다. 문구를 못 찾으면 쪽 이동만 하고 상단에 `근거 문구: "…"`를 띄운다.
- **도구:** 쪽 이동(이전/다음, 쪽 번호 입력), 확대·축소, 원본 PDF 내려받기, `청약홈에서 보기 ↗`.
- **원본 출처 표기:** 뷰어 상단에 `출처: 청약홈 입주자모집공고문 · 수집 10.17(토)`.
- **대체 경로:** 뷰어를 띄울 수 없는 환경(구형 브라우저, 뷰어 로드 실패)에서는 PDF를 새 탭으로 열고 `#page=N`을 붙인다.
- **기본안은 자체 뷰어**로 한다. 서비스가 저장한 PDF 사본을 보여 주는 것이 청약홈·공공데이터 이용 조건에 맞는지 3주차 전에 확인한다(D-04).
- **대안 (컷 순서 1번):** 이용 조건상 안 되거나 4주차 끝에 일정이 밀리면, 원문 보기는 청약홈 링크로만 제공하고 근거 칩은 쪽 번호와 문구 미리보기까지만 제공한다(PRD F6-2, 5.4).

**관련 검수:** #9

## 6. 검수 시나리오

6주차 통합 테스트(SCHEDULE)의 기준. 실제 공고 데이터로 확인한다. 번호는 상위 문서 1장 추적표가 참조하므로 바꾸지 않는다(18~22는 [ALERTS.md 6장](ALERTS.md#6-검수-시나리오)).

| # | 시나리오 | 기대 결과 |
|---|---|---|
| 1 | 첫 방문 | 접수 예정 + 접수 중 공고만, 접수 임박순으로 나온다 |
| 2 | 지역 서울·경기 + 신혼부부 선택 | 두 지역의 공고 중 신혼부부 세대수 1 이상인 주택형이 있는 공고만 나오고, 무순위·재공급 제외 배너가 뜬다 |
